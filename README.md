# SearchReady Site Builder — SEO-First Website Design & Development Skill

**Previous visual candidate:** v0.3.0 visual-direction review, built on the previously validated v0.2.0 Skill. The new Clearroom and Cinderline art direction requires owner visual acceptance and targeted Windows HTTP/Chrome verification. **Not a production website, WCAG, or search-ranking certification.**  
**Purpose:** Help an AI coding assistant transform a beginner's idea into a distinctive, useful website with foundational technical and on-page SEO integrated into design, content, implementation, QA and release preparation.

## What it handles

- Planning and effort estimates using a realistic goal, audience, site map and conversion path.
- Custom visual systems, mobile-first layouts, accessible navigation and functional UI components.
- Useful, original content structures and metadata written for real visitor intent.
- Technical SEO foundations: crawlable HTML, links, URL plan, titles, descriptions, image alt, canonicals, robots/sitemaps, migration/redirect plan, truthful structured data.
- Performance budgets, security/privacy review, responsive/browser tests, staging vs production gates, source-based recovery and handover.
- Minimal repeated tests, honest PASS/FAIL/BLOCKED evidence and independent review before final publication.

## What it does not guarantee

Search ranking, indexing, backlinks, business content authenticity, SEO traffic, perfect Core Web Vitals, real-world accessibility conformance, hosting/domain availability, or automatic Search Console setup. Successful use depends on the selected model, tools, permissions and authoritative business details.
