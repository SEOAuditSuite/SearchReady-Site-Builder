# Contributing

Please open an issue describing a reproducible website-design, technical SEO, accessibility or functional issue. Include affected files, screenshots when helpful, and the applicable verification layer. Do not include private data or credentials.

Changes should be narrow, preserve existing examples and manifests, and identify which tests are new, PASS, FAIL, BLOCKED or NOT RUN. Do not overclaim SEO rankings, WCAG certification, security or live Core Web Vitals.
