# Security policy — candidate distribution

This open-source Skill is guidance and examples, not a hosted service or security guarantee.

To report a suspected security issue, use a private security advisory in the GitHub repository if enabled, or contact the repository maintainers privately. Do not disclose passwords, customer records, or production tokens in a public issue.

The sample request form is localhost-bound and stores fictional data in a local SQLite file. **Do not expose the sample server to the public Internet.** A production form requires its own review covering HTTPS, secure cookies, anti-abuse controls, privacy/retention, operational monitoring, and service ownership.
