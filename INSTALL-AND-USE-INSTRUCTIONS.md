# SearchReady Site Builder — Beginner Installation and Use

## Option A — ChatGPT Project setup (recommended for users without native Skills access)

1. Create one ChatGPT Project for the website you want to build (example: `My Business Website`).
2. Open that Project's instructions/settings. Copy and paste the complete text from `PROJECT-INSTRUCTIONS.txt` and save it.
3. Upload these **two files** as Project references: `SKILL.md` and `SEARCHREADY-REFERENCE-GUIDE.md`. You may additionally upload `templates/SITE-BRIEF.md` when starting a larger site.
4. Start a new chat *inside the same Project* and say: "Use SearchReady Site Builder to plan a professional SEO-ready website for my business. Begin with the brief, recommended design direction, page map and realistic estimate. Do not publish anything yet."
5. Provide truthful facts and any original brand assets when asked. Review a short plan and let ChatGPT use supported workspace/browser tools. If a task cannot run in normal Chat, use an eligible tool-enabled workflow and retain the actual source/checkpoint files.
6. Continue in the same Project. For a new chat: "Resume from the current source/checkpoint. Check what is already verified; do not redo completed work."
7. Before launch, request the production-readiness checklist and evidence for the real domain, forms, SEO, keyboard/responsive behavior and performance. Deploy only after approving it.

**Note:** Project files are reference/instruction material, not a native installable Skill. They do not automatically gain the ability to edit local files, click browsers or deploy.

## Option B — Native Skill installation (only where supported)

1. Check your ChatGPT workspace's current Skills feature and account eligibility in official help or the UI. Availability can change.
2. Use the native Create/Upload/Install entry point that your workspace actually provides. If it accepts skill packages, supply the package/folder in the format it requests, keeping `SKILL.md` and `references/` together.
3. Verify that `searchready-site-builder` is visible and activated in a new supported chat before treating it as installed. If the interface does not offer Skills, use Option A; do not search for hidden menus.
4. Give a beginner-friendly website brief as in Option A. Actual execution capabilities still depend on permissions/tools.

## Start with one sentence

> Build a fast, professional, mobile-friendly, SEO-ready website for my [real business type] serving [region], focused on [customer action]. Use my supplied facts; don't invent credentials. Give me a short plan and estimate, then build and test without publishing until I approve.

## Troubleshooting

- **SEO tags missing:** distinguish source HTML and browser-rendered DOM. Ask for the specific route and evidence.
- **Site looks good but links/forms don't work:** require real HTTP/browser journeys, not a screenshot or static checker.
- **Missing canonical/sitemap:** provide the approved production domain first; do not invent it.
- **Accidental noindex:** keep demo/staging controls separate; verify real production responses before launch.
- **Chat forgets:** reattach actual workspace and checkpoint files; never rely only on previous message memory.
- **Model says 100% ready without evidence:** ask for exact test URLs, revision, captured artifacts, unverified gates and a release verdict.

## Which files to upload?

For ChatGPT Project users: **only `SKILL.md` and `SEARCHREADY-REFERENCE-GUIDE.md` are required** plus pasted `PROJECT-INSTRUCTIONS.txt`. The full ZIP is for download, backup and supported native/agent setups; do not assume uploading only ZIP makes its contents fully available.

## Platform selection and optional SEO integrations (v0.3.1)
The same two required Project files and pasted instructions are sufficient for the standalone workflow. Tell the agent “Build my Shopify store,” “Build my WordPress site,” or “Recommend a platform for my business.” The agent must identify actual platform access before execution. Optionally provide BeyondSEO separately if you have the right to use it, or authorize a compatible SEO Audit Suite. Neither is included or needed for basic setup. Never paste API tokens into Project instructions. WordPress/WooCommerce/Shopify runtime acceptance is pending; this candidate is not a certified platform integration.
