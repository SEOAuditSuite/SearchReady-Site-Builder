# Pilot 02 — Fictional Local Service Site

**User brief (representative):** “Build a modern, professional five-page site for a bicycle-repair service. The site should have clear tune-up and repair pages, helpful advice, mobile usability, basic built-in SEO, and a service-request form. Don't fake a business address, pricing, testimonials or an actual booking service.”

## Intended audience and conversion
- Audience: everyday bicycle riders seeking a clear explanation of service options.
- User jobs: understand regular tune-ups; diagnose categories of repair concerns; understand a transparent process; submit a simulated request in a local demo.
- Primary conversion: **save a fictional service request locally**. Not a live booking or business lead.
- Locale/real business identity: unverified; geographic SEO intentionally deferred.
- Design direction: editorial service-studio aesthetic with muted forest, ivory and terracotta; custom original SVG bicycle illustration; no stock photos or external CDNs.
- Stack: Python 3.12+ standard library for server and SQLite; HTML/CSS/vanilla JS for frontend, server-rendered primary content. Distinct from the static first pilot.
- Restrictions: localhost only, dummy details, no public deployment, no real-world LocalBusiness schema, no real contact backend or payment.

## Estimation evidence
No documented pre-implementation estimate was captured for this isolated pilot. The Skill's “forecast before build” behavior is **NOT VERIFIED** by this pilot; it should be evaluated separately, not retroactively marked PASS.
